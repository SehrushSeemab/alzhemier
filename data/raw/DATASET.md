# Dataset

This project uses a subset of the Alzheimer's Disease Neuroimaging Initiative (ADNI) dataset prepared for the TADPOLE Grand Challenge.

The dataset is subject to the ADNI and TADPOLE data use agreements and is therefore **not included** in this repository.

To reproduce this project:

1. Register with the ADNI project.
2. Obtain access to the ADNI/TADPOLE dataset.
3. Download the required dataset.
4. Place the downloaded files inside the `data/raw/` directory before running the notebook.

## Official Sources

- ADNI: https://adni.loni.usc.edu/
- TADPOLE Grand Challenge: https://tadpole.grand-challenge.org/
